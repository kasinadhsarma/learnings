# Learnings

Personal collection of code notes and examples used while learning Python and TypeScript/JavaScript.

## Structure

```
python/
  loops/          for, while, and conditional loops; break/continue/else; error handling
  oops/           classes & objects, inheritance, encapsulation, polymorphism, abstract classes
learnings/        TypeScript concepts paired with their compiled JS output
  (types, generics, unions & intersections, discriminated unions, utility types, any vs unknown)
typescript-interview-notes.md   TypeScript interview prep notes
```

## Usage

Python examples can be run directly:

```bash
python3 python/oops/abstract/abstractbaseclass.py
```

TypeScript examples in `learnings/` can be compiled and run with `tsc` and `node`, or run directly with `ts-node`.
